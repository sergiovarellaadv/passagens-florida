# Passagens Natal–Flórida

Monitor de preços no Google Voos (Natal, Recife e Fortaleza para Orlando,
Miami, Tampa e Fort Lauderdale, ida de 26/12 a 01/01). Roda sozinho no
GitHub Actions a cada 2 horas e publica o painel no GitHub Pages.

- Painel: aba **Settings > Pages** mostra o link (termina em `.github.io/passagens-florida/`)
- Histórico em planilha: `historico.csv`
- Registro de cada busca: `log.txt`
- Configuração (destinos, datas, preço-alvo, deslocamento): `config.json`
- Rodar na hora: aba **Actions > Monitor de passagens > Run workflow**
- Parar: aba **Actions > Monitor de passagens > ... > Disable workflow**
